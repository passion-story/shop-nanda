# 샵난다

[샵난다](https://smartstore.naver.com/shopnanda) 상품 소개 웹사이트 
<!-- — https://passion-story.github.io/shop-nanda -->

[Astro](https://astro.build) 기반 정적 사이트입니다.

## 개발

Node.js 22 이상

```bash
npm install
npm run dev     # 개발 서버 (http://localhost:4321)
npm run build   # dist/ 생성
npm run check   # 타입 검사
```
